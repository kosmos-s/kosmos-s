# kosmos-s

컴퓨터공학을 공부하며 **서버·인프라, 자동화, 게임 개발** 프로젝트를 직접 만들고 운영하면서 기록하고 있습니다.

## Featured Projects

### 🖥️ Home Game Server

**Ubuntu + Pterodactyl 기반 홈 게임 서버 인프라**

개인 PC에서 실행하던 게임 서버를 SER8 전용 미니 PC로 분리하고, Ubuntu·SSH·Webmin·Pterodactyl을 이용해 Minecraft, Palworld, Project Zomboid 서버를 운영한 프로젝트입니다.

[Repository →](https://github.com/kosmos-s/home-game-server)

---

### 🤖 깐보's Ptero

**Discord × Pterodactyl 서버 상태 현황판 봇**

Discord 사용자가 현재 어떤 게임 서버가 열려 있는지 바로 확인할 수 있도록 만든 Node.js 봇입니다. Pterodactyl Client API를 이용해 서버 상태와 업타임을 조회하고 상태 변경 알림을 제공합니다.

[Repository →](https://github.com/kosmos-s/kkanbo-ptero)

---

### ⚙️ Pterodactyl Minecraft Multi-Profile Manager

**하나의 Pterodactyl 서버 슬롯에서 여러 Minecraft 프로필을 관리하는 오픈소스 도구**

하나의 Primary Allocation을 유지하면서 여러 독립 Minecraft 서버 폴더를 저장하고, 선택한 프로필 하나만 실행할 수 있도록 만든 Pterodactyl Egg 프로젝트입니다. 서버 종류와 Minecraft 버전을 감지하고 Java 버전 선택, 프로필 전환 백업 등을 자동화합니다.

[Repository →](https://github.com/kosmos-s/pterodactyl-minecraft-multi-profile-manager) · [한국어 문서 →](https://github.com/kosmos-s/pterodactyl-minecraft-multi-profile-manager-ko)

### 🎮 GPT Roguelike

**Roblox 3D 생존 로그라이트 개인 프로젝트**

Roblox Studio와 AI를 활용해 자동 공격, 직업·스킬, 아이템 빌드, 영구 성장, DataStore 저장 등 반복 플레이 구조를 구현하고 회귀 테스트와 문제 해결 과정을 기록하고 있습니다.

[Repository →](https://github.com/kosmos-s/gpt-roguelike)

## What I Focus On

- 직접 사용하고 운영하면서 발견한 문제를 해결하는 프로젝트

- Linux, Docker, Pterodactyl을 활용한 홈 서버 운영과 자동화
- API를 이용한 서비스 연동
- 게임 시스템 구현과 반복적인 플레이 테스트
